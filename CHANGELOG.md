# Changelog

## 0.2.0 (unreleased)

First complete build of all ten phases. Highlights:

- Glass UI (Phase 1), Core service with a secured named pipe and real hardware detection (Phase 2).
- Usage Monitor with real per-app CPU/GPU/memory/I/O and process actions (Phase 3).
- PC Boost: 20 tweaks as data with snapshot/revert, RAM Cleaner, DNS Optimizer (Phase 4).
- Library and Game Mode with an automatic revert watchdog (Phase 5).
- Per-app network traffic (ETW), connections, Traffic Shaper with Firewall and QoS (Phase 6).
- Quality Test with bufferbloat, route analysis, MTU, Multi Internet failover (Phase 7).
- Benchmark Lab with frame-time capture from DXGI events (Phase 8).
- OTX Relay server (authenticated, allow-listed, rate-limited) and relay latency test (Phase 9).
- Measured performance budgets, documentation, release workflow (Phase 10).

Known gaps are listed in PROGRESS.md.
